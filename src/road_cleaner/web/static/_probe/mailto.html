Which of these opens your mail client?

Click each in order. The point is to find where it stops working. If #1 already does nothing, the problem is your Mac's mailto handler, not anything in Road Cleaner.

  1. 1. Bare address, nothing else
    mailto:contact@dot.ga.gov
  2. 2. Subject, one word, no spaces
    mailto:contact@dot.ga.gov?subject=Test
  3. 3. Subject with an encoded space
    ?subject=Road%20hazard — your spacing theory
  4. 4. Subject + short body with newlines
    %0A%0A line breaks
  5. 5. The exact link the case page builds
    same length and encoding as the real one

Nothing here sends anything. These only ask the operating system to open a draft — the same thing the case page's button does.
